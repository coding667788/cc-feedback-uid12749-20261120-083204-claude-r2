实现离线服务身份退役协调器。服务绑定多条凭据并定义每类操作最少可用身份数；身份有租户、代数、授权动作及退役阶段。prepare 固定候选和旧凭据存续截止，迁移可分批且只限同租户，取消不回滚已提交迁移。凭据资格以绑定身份当前代数与时窗判断，已撤销的代数不会复活。

用 SQLite 持久化，任何 finalize 或迁移批次必须以事务内当前时间及状态验证全部受影响服务的覆盖，并在同一事务保存变更与回执。读者可查询给定时刻到下一个已知凭据边界为止的覆盖证据。构造候选覆盖数量达标但动作不足、两个身份各自退役可行同时失败、恰好到期、取消后再次 prepare 等样例；用独立进程及真实终止在提交前后验证只有可线性解释的结果。

覆盖计数按合格身份去重。同一身份下的两份凭据只贡献一个席位；覆盖整批检查对象包括变更前后受影响的服务并集。

并发测试用同步点固定先后。只终止本题启动的测试子进程。请求 ID 在租户内唯一，同 ID 同参数返回已持久化的第一次结果，异参拒绝。未提交中断以重启后的数据库状态判断，业务失败的回执应与业务状态区分。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
